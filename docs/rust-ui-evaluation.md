# Rust/UI Evaluation

## Evaluation Criteria
- Cross-platform capability (web + mobile)
- Developer experience
- Performance
- Ecosystem maturity
- Integration with Rust backend

## Decision
Dioxus selected as it provides a unified Rust-based UI for web and mobile with good ergonomics and strong Rust integration. The template is structured to allow swapping if needed, but Dioxus meets the requirements for this template.
